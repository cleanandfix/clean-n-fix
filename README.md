# 클린앤픽스 웹사이트 (VS Code 수정용)

## 폴더 구조
- `index.html` : 메인 페이지 마크업
- `css/style.css` : 전체 스타일 및 프라이머리 컬러(`#0050aa`) 설정
- `js/main.js` : 클리닝 공정 8단계 데이터, FAQ 아코디언, 견적 신청 모달 스크립트
- `assets/` : 히어로 배너(`hero-sofa-care.jpg`) 및 공정별 이미지(`step-01.jpg` ~ `step-08.jpg`)를 넣는 폴더

## VS Code에서 여는 방법
1. `cleanfix-vscode-project.zip` 파일의 압축을 풉니다.
2. VS Code에서 **파일(File) > 폴더 열기(Open Folder)**를 눌러 `cleanfix-vscode-project` 폴더를 선택합니다.
3. 실제 보유하신 사진 파일들을 `assets/` 폴더 안에 이름에 맞춰 넣으면 화면에 바로 반영됩니다.
   - `assets/hero-sofa-care.jpg`
   - `assets/step-01.jpg` ~ `assets/step-08.jpg`
